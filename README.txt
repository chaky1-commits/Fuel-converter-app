Fuel Converter PWA

[GitHub Pages 배포]
1. 새 저장소 생성 (예: fuel-converter)
2. 이 폴더의 모든 파일(index.html, manifest.webmanifest, sw.js, icons/)을 저장소 루트에 업로드
3. Settings > Pages > Branch: main / root 선택
4. https://<username>.github.io/fuel-converter/ 접속

[홈 화면에 설치]
- iPhone: Safari로 접속 > 공유 > 홈 화면에 추가
- Android: Chrome으로 접속 > 메뉴 > 앱 설치 / 홈 화면에 추가
설치 후에는 오프라인에서도 동작합니다.
